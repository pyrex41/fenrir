Walk the repository

The folders are stages of one pipeline. A .fen file becomes JSON. A Shen machine steps those bytes, and a Shen compiler emits ARM64 from the same bytes. Gleipnir compares what they observe.

Click a box to jump to that stop. The same walk, with Mermaid, is WALKTHROUGH.md — that is the page GitHub renders. This file is the one to open in a browser.

Two hosted paths

Stop 1

The claim

Two runs can return the same value and still disagree. In the cancellation example both sides return 42. Before the fix, the native runtime also emitted child. The harness compares the ordered events, not only the answer.

  • README.md
  • tests/native/discontinue-joins-child.fen

Stop 2

A program you can hold

main is the entry point. This one sums 1 through its input, unless the input is above 500. The other short files in examples/ are arithmetic, closures, and handlers. Leave examples/service and examples/remote until the pipeline is familiar.

  • examples/recursive-sum.fen

Stop 3

How the text is spelled

The surface is a draft. It elaborates into a versioned artifact schema. What a program means is the Shen model. The standalone profile allows 16 live child tasks.

Stop 4

Text becomes bytes

The header of main.shen is the contract of the pipeline: the elaborator writes an artifact, a JavaScript validator judges those exact bytes, and the model runs what it decodes from the same bytes. Nothing in the frontend interprets a program. typing/ is a separate Shen checker, used only when FENRIR_REQUIRE_SHEN_TYPING=1.

  • frontend/fenrir.sh
  • frontend/main.shen
  • frontend/reader.shen
  • frontend/elaborate.shen
  • frontend/validate.mjs

Stop 5

The rules

Read the two headers and stop. The task machine adds scopes, channels, and cancellation on top of the handler machine. A step that is not one of those is the handler machine’s own step. A schedule is an input: one step runs the task it is given. models/tc0 is the earlier pure-call machine, including decimal I64 arithmetic. Open it when a TC0 gate is the question.

  • models/tc1/handler-machine.shen
  • models/tc1/task-machine.shen

Stop 6

The other reader

emit.shen parses the artifact and selects ARM64 instructions. The C runtime is the heap, the managed collector, and the scheduler. bin/fenrir calls tools/aarch64/native-image.sh, then clang for macOS, or a Solo5 link inside Docker when the host is not Linux ARM64.

  • backends/arm64/emit.shen
  • runtime/native/scheduler.c
  • tools/aarch64/native-image.sh

Stop 7

One CLI, then a fork

model, check, and build all emit an artifact first. model runs it on the Shen machine. check stops once the program lowers for the target. build assembles and links. run builds, then executes. Record and replay go through tools/aarch64/native-replay.py.

  • bin/fenrir

Stop 8

Where a disagreement is kept

The harness and the model share one Shen process. A useful failure is a small program, a schedule, and the first observation that differs. Native regressions are .fen files under tests/native.

  • harness/README.md
  • tests/native/discontinue-joins-child.fen

Stop 9

The durable job

The worker describes the writes. The OTP host authenticates the tenant and commits them in one SQLite transaction. On a retry with the same digest the model returns the original receipt. This host is host/service, not supervisor/.

  • docs/PREVIEW.md
  • examples/service/accepted-job.fen
  • host/service/README.md
  • models/service/accepted-job.shen
  • spec/service/HANDLER.md

Stop 10

Remote perform

A system is one image per member plus this supervisor, which sits outside the images and carries every message. A remote operation returns a reply, not_delivered, or timed_out. The model of that system is remote-system.shen.

  • supervisor/README.md
  • models/tc1/remote-system.shen
  • examples/remote/ledger-caller.fen

Stop 11

Sections 1 and 2 of the direction amendment are enough. Where that file conflicts with the full vision or the phased plan on direction, it is the newer statement. The tiny-language document remains the TC0 contract. History, campaigns, and performance dumps are records of a date, not the map.

  • docs/design/04_DIRECTION_AMENDMENT.md
